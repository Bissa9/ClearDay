# Contributing

Thanks for taking a look at ClearDay.

1. Fork the repository and create a focused branch (`feat/task-reminders`, for example).
2. Keep domain rules out of React components where practical.
3. Run `npm run typecheck` and `npm run build` before opening a pull request.
4. Describe user-visible changes and include screenshots for visual updates.
5. Never commit credentials, `.env` files, or real personal task data.

Ideas for contributions: automated tests, keyboard shortcuts, export/import, optional reminders, and an API-backed sync adapter.
